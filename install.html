💬 카카오톡에서 여셨네요

카카오톡 안의 화면에서는 설치가 안 돼요. 아래 버튼으로 브라우저에서 열어 주세요.

버튼이 안 되면 오른쪽 아래 ⋮ 또는 공유 → "다른 브라우저로 열기"를 누르세요.

🤖 안드로이드

  1. 크롬: 오른쪽 위 ⋮ → "앱 설치" 또는 "홈 화면에 추가"
  2. 삼성 인터넷: 아래 ≡ → "현재 페이지 추가" → "홈 화면"
  3. 홈 화면에 생긴 🍜 아이콘으로 실행하세요.

🍎 아이폰

  1. 반드시 사파리(Safari)로 여세요.
  2. 화면 아래 공유 ⬆️ 버튼을 누르세요.
  3. 목록을 내려 "홈 화면에 추가" → 오른쪽 위 "추가"
  4. 홈 화면에 생긴 🍜 아이콘으로 실행하세요.
